# Repository Guidelines

## Documentation placement

- Keep only repository entry and governance documents at the repository root, such as
  `README.md`, `AGENTS.md`, `CONTRIBUTING.md`, `CHANGELOG.md`, and `SECURITY.md`.
- Put plans, designs, runbooks, reports, handovers, and other project documentation under
  `docs/`. Never create a new planning document at the repository root.
- Move completed or superseded documents that still have audit value to `docs/archive/`.
  Delete a document only when its useful content is fully covered elsewhere.
- Update relative links and cross-references whenever documentation is moved.
